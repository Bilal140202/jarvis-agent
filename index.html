jarvis-agent

A native Android personal AI assistant

Jarvis Agent is a native Kotlin Android personal AI assistant: AccessibilityService-based phone control, multi-provider LLM support, voice control, a Telegram remote, and skill memory. An installable APK ships in the repository's download folder.
